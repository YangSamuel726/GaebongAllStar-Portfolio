### 1. 배경과 목표
  Gaebong All Stars는 여러 캐릭터의 스킬이 서로에게 영향을 주는 온라인 PvP 게임입니다. 캐릭터의 상태에 따라 어떤 행동과 스킬을 허용할지 판단해야 하며, 새로운 스킬을 추가하면서 이 판단에 사용되는 상태도 늘어났습니다.<br>
초기에는 상태를 enum으로 구분하고, 각 행동의 조건 검사 코드에서 관련 상태를 직접 나열했습니다. 상태들이 어떤 상위 분류에 속하는지는 코드의 분기 조건에 암묵적으로 담겨 있었습니다. 따라서 같은 행동 제한을 가진 상태를 추가하더라도, 해당 분류를 검사하는 여러 코드를 찾아 수정해야 했습니다.
이를 해결하기 위해 상태의 상하위 관계를 데이터로 정의하는 태그 시스템을 설계했습니다. 행동 조건은 상위 태그를 검사하고, 개별 상태는 그 하위에 등록하도록 구성했습니다. 같은 분류의 상태가 추가되어도 기존 조건 검사를 유지하는 것이 목표였습니다.
