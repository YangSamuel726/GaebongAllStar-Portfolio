# GaebongAllStar-Portfolio
GaebongAllStar는 2~10인이 함께 즐기는 온라인 PvP 액션 게임입니다.
개성 있는 캐릭터와 다양한 아이템을 활용해 예측할 수 없는 전장에서 속도감 있는 전투의 재미를 제공합니다.
