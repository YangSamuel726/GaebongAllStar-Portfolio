## 1. 게임 소개
GaebongAllStar는 2~10인이 함께 즐기는 실시간 온라인 PvP 액션 게임입니다.
각자의 캐릭터와 아이템, 맵을 활용해서 적을 모두 쓰러뜨리는 것을 목표로 하는 게임입니다.

## 4. 핵심 기술 경험
