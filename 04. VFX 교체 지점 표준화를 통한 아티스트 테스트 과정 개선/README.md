### 문제 해결 요약
> 문제: VFX 연결 위치가 여러 프리팹과 스크립트에 분산되어 테스트마다 개발자의 안내가 필요했습니다.<br>
> 해결: 역할명이 지정된 VFXSO를 중간 참조로 두고 리소스 교체 지점을 통일했습니다.<br>
> 결과: 현재 71개의 VFX 에셋이 동일한 작업 방식을 사용하며, 반복 테스트 과정에서 개발자의 개입을 줄였습니다.

### 1. 기존 테스트 과정과 문제
- 아티스트가 제작한 VFX는 캐릭터의 스킬이나 아이템에 연결한 뒤, 실제 게임에서 크기·위치·재생 시간을 확인하는 과정이 필요했습니다.
- 기존에는 VFX 연결 지점이 캐릭터, 무기, 투사체 등 여러 프리팹과 스크립트에 분산되어 있었습니다. 프로젝트 내부 구조를 알지 못하는 아티스트가 직접 연결 위치를 찾기 어려웠기 때문에, 리소스를 교체하고 테스트할 때마다 개발자에게 위치를 확인해야 했습니다.
- 이로 인해 아티스트는 개발자의 안내를 받기 전까지 테스트를 시작하기 어려웠고, 개발자도 작업 도중 반복적으로 연결 위치를 찾아 설명해야 했습니다. 캐릭터와 아이템이 추가될수록 VFX의 수와 연결 지점도 함께 늘어나기 때문에, 같은 문제가 계속 반복될 것으로 예상했습니다.

<img src="./VFX_WorkFlow_Images/이전 테스트 과정 흐름.png" width="650">

### 2. 해결 목표
- 아티스트가 캐릭터 프리팹과 스크립트 구조를 몰라도 VFX를 교체할 수 있게 한다.
- VFX의 교체 지점을 일정한 폴더와 에셋으로 통일한다.
- 새로운 캐릭터와 아이템이 추가되더라도 동일한 작업 방식으로 테스트할 수 있게 한다.
- 반복적인 리소스 교체 과정에서 개발자의 개입을 최소화한다.


### 3. 선택한 구조와 작업 흐름
- 실제 VFX 프리팹을 직접 참조하는 대신, VFX 프리팹을 감싸는 역할별 `VFXSO` 에셋을 만들었습니다. 캐릭터의 스킬과 아이템은 실제 VFX 프리팹이 아니라 이 에셋을 참조합니다.
각 VFXSO는 다음과 같이 사용되는 위치와 역할을 알 수 있는 이름으로 관리했습니다.
<img src="./VFX_WorkFlow_Images/프로젝트 내 VFXSO 에셋.png" height="200"> <img src="./VFX_WorkFlow_Images/VFXSO 인스펙터.png" height="200">

- 개발자는 새로운 기능을 구현할 때 해당 역할의 VFXSO를 한 번 생성하여 스킬이나 아이템에 연결합니다. 이후 아티스트는 캐릭터나 무기 프리팹을 열지 않고, 정해진 VFX 에셋 폴더에서 역할에 맞는 에셋을 찾아 vfxPrefab만 교체할 수 있습니다.
- VFX 프리팹을 교체해도 스킬과 아이템이 참조하는 VFXSO는 그대로 유지되므로, 리소스가 수정될 때마다 관련 스크립트와 프리팹을 다시 설정할 필요가 없습니다.

### 4. 적용 결과
- 아티스트는 리소스가 연결되는 캐릭터·무기 프리팹의 내부 구조를 알지 못해도, 역할명이 지정된 VFXSO를 통해 리소스를 직접 교체하고 테스트할 수 있게 되었습니다.
- 개발자의 작업은 새로운 기능을 추가할 때 VFXSO를 생성하고 최초 연결하는 과정으로 한정됐습니다. 이후 반복되는 VFX 수정과 테스트 과정에서는 연결 위치를 다시 설명할 필요가 줄었습니다.
- 현재 프로젝트에서는 71개의 VFXSO 에셋이 같은 방식으로 관리되고 있어, 특정 기능에만 적용한 임시 해결책이 아니라 캐릭터와 아이템 전반에서 사용하는 공통 작업 방식으로 확장됐습니다.
